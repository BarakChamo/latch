---
title: Package scripts
description: Run existing JavaScript or Python checks without writing a Latch config.
---

Name a package script for the event you want. Latch reads the manifest in the
harness or CLI working directory.

## JavaScript and TypeScript

```json title="package.json"
{
  "scripts": {
    "hook:afteredit": "prettier --check src",
    "hook:turnend": "tsc --noEmit && vitest run --no-color"
  }
}
```

Install the project's dependencies first. This example uses Prettier,
TypeScript, and Vitest. Latch uses `packageManager` to select
npm, pnpm, Yarn, or Bun. Without that field, it uses the local lockfile or
defaults to npm. If lockfiles point to different managers, set `packageManager`
explicitly.

If your npm project already has a `test` script, set
`"hook:turnend": "npm test"` to reuse it.

## Python with uv

```toml title="pyproject.toml"
[project.scripts]
hook-afteredit = "latch_python_example.checks:after_edit"
hook-turnend = "latch_python_example.checks:turn_end"
```

Use a packaged Python project with a build system. Replace
`latch_python_example.checks:after_edit` and `:turn_end` with the Python
functions that run your project’s checks and return their exit status.
Install `uv` on the harness’s `PATH`. Latch invokes the entry points with
`uv run hook-afteredit` and `uv run hook-turnend`.

If you already run commands such as `uv run ruff check .` or
`python -m unittest`, you can [configure those commands directly](/docs/configuration)
without packaging Python entry points.

When both manifests define the same event, JavaScript runs before Python.
The scripts inherit any [defaults in `latch.json`](/docs/configuration#ordering-and-overrides).

## Try the examples

From a Latch checkout, choose an example and run its checks.

### TypeScript example

```sh
cd examples/typescript
npm ci
latch run after_edit
latch run turn_end
```

Use Node.js 22.12 or newer. Change `Hello` to `Hi` in `src/message.ts`,
then rerun `latch run turn_end` to see the Vitest assertion.

### Python example

```sh
cd examples/python
uv sync --locked
latch run after_edit
latch run turn_end
```

Add an unused import to `src/latch_python_example/__init__.py` and rerun
`latch run after_edit` to see Ruff's diagnostic. Remove the import and change
`Hello` to `Hi` to see a unit test fail with `latch run turn_end`.
