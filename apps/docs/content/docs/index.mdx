Latch runs your project’s linters, tests, and other checks as your coding agent works, and brings failures back into the session.

[Quickstart](/docs/quickstart) · [Compatibility](#compatibility) · [CLI install](/docs/cli#install-the-cli) · [Examples](#examples)

## When to use Latch

Use Latch when you want your agent to see whether its changes pass your project’s checks without asking it to run them. Run fast checks, such as lint or formatting, after an edit so failures are easy to trace. Run tests, builds, or broader checks at the end of the turn, once the related edits are in place.

Start with one command you already run locally or in CI. [Install a plugin and run your first check](/docs/quickstart)

## How it works

| Event | Use it for |
| --- | --- |
| `after_edit` | Fast checks after a supported native file edit, such as lint or formatting. |
| `turn_end` | Checks that should run once after a changed turn, including turns with shell edits. |

Latch compares Git-visible changes across the event. Read-only turns and no-op edits skip checks by default, even in an already-dirty worktree. Path and extension filters narrow which checks run. Passing checks are quiet. Long failure output can be shortened and linked to the original log. [Hook lifecycle](/docs/hooks) · [Filters and output settings](/docs/configuration)

Name a script in `package.json` or an entry point in `pyproject.toml` to get started. Add `latch.json` when you want explicit commands, filters, or shared settings. [Package script discovery](/docs/project-scripts) · [Configuration and JSON schema](/docs/configuration)

## Compatibility

The default delivery of failures depends on the agent and event. For a supported agent, opt in to `"turn_end_feedback": "continue_once"` to give it one chance to respond to a failed turn-end check automatically, without another message from you or an automatic recheck. [Local and cloud compatibility matrix](https://github.com/BarakChamo/latch#compatibility) · [Opt-in turn-end feedback](/docs/hooks#act-on-a-turn-end-failure)
