Your agent finishes an edit. You run your tests, find a failure, and
paste the error back into chat. Latch takes care of that step for you.

Latch runs your project’s own formatters, linters, type checkers, and tests
at the points you choose. It uses Git to skip unchanged work and stays
quiet when checks pass. When a check fails, the harness can pass the
diagnostic to the agent after an edit or on a later prompt. A shortened
report can link to the original output for follow-up.

## A typical setup

Run lint after edits and keep the test suite for turn end. Put these
commands in `latch.json` next to your project's `package.json`.

```json title="latch.json"
{
  "hooks": {
    "after_edit": { "commands": [["npm", "run", "lint"]] },
    "turn_end": { "commands": [["npm", "test"]] }
  }
}
```

The same configuration travels with your repository. Your teammates can
use different agents, and you can run the turn-end checks yourself with
`latch run turn_end`. See [when hooks fire and where reports go](/docs/hooks).
